# خاتمة «اكتشافات» المتحركة

| الملف | الوظيفة |
|---|---|
| `outro_animated.html` | تصميم الحركة (الشعار، الزخرفة الرافدينية، الكلمات السومرية) |
| `render_outro.js` | تحويل التصميم إلى فيديو |
| `sfx_outro.py` | توليد المؤثرات الصوتية برمجياً (بدون ملفات صوت خارجية) |
| `sfx/` | المؤثرات منفصلة (لمسار SFX في دافنشي) + `sfx_outro_mix.wav` الممزوج |

## توقيت الصوت مع الصورة (6 ثوانٍ)

| الوقت | الصورة | الصوت |
|---|---|---|
| 0 – 6 ث | الزخرفة تتحرك | نغمة عميقة ممتدة (D و A) + رمل خفيف |
| 0.3 – 1.9 ث | كشف الشعار | صوت هواء يتصاعد (riser) |
| 1.9 ث | اكتمال الشعار | ضربة سينمائية عميقة |
| 2.0 – 3.2 ث | اللمعان الذهبي | رنين ناعم |
| 2.6 / 3.1 / 3.6 ث | الكلمات السومرية | نقرة «لوح طيني» لكل كلمة |

مستوى الصوت: ‎-15.7 LUFS، الذروة ‎-0.8 dBFS.

## إعادة التوليد (يقوم بها Claude Code)
```
python assets/outro/sfx_outro.py assets/outro/sfx
node assets/outro/render_outro.js 1920 1080 out_16x9.mp4
node assets/outro/render_outro.js 1080 1920 out_9x16.mp4
ffmpeg -i out_16x9.mp4 -i assets/outro/sfx/sfx_outro_mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k outro_16x9_sound.mp4
```

## الكلمات السومرية
𒅆 igi (يرى) ← 𒍪 zu (يعرف) ← 𒅆𒊒 pàd (يجد/يكتشف).
يُنصح بمراجعتها مع متخصص قبل النشر.
