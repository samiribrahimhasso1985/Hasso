# اختبار المرحلة 1 على فيديو عربي حقيقي

لا ننتقل إلى المرحلة 2 قبل إكمال هذا الاختبار. الهدف: معرفة هل توقيت الكلمات
العربية (واللهجة العراقية) دقيق فعلاً، وليس افتراض ذلك.

## ما الذي تم اختباره مسبقاً (في بيئة التطوير)
- حفظ الأصل والتحقق بالبصمة، وجعل النسخة للقراءة فقط ✓
- قراءة MP4 / WAV وكشف النسبة 9:16 ✓
- استخراج الصوت 16kHz أحادي ✓
- تعليم الكلمات المشكوك فيها وكشف مناطق الصوت بلا نص (بمحرك تجريبي وهمي) ✓
- الاستئناف بعد التوقف وتسجيل الخطأ ✓

## ما الذي **لم** يُختبر بعد
- تشغيل WhisperX فعلياً على كلام عربي (لم يكن تحميل النماذج متاحاً في بيئة التطوير).
- دقة المحاذاة للهجة العراقية.
- التثبيت على Windows 11 (ملفات .bat).

## خطوات الاختبار

استخدم فيديو قصيراً (1–3 دقائق) بصوتك ولهجتك العادية.

1. شغّل `setup_windows.bat` وتأكد من ظهور «النظام جاهز ✓». سجّل:
   هل يوجد كرت NVIDIA؟ ________
2. اسحب الفيديو فوق `analyze_video.bat`. سجّل مدة التحليل: ________
3. في صفحة المراجعة، اختر **20 كلمة عشوائية** (من البداية والوسط والنهاية) وانقر عليها:

| # | الكلمة | النص صحيح؟ | الصوت المسموع يطابق الكلمة؟ | يبدأ متأخراً / مبكراً / مضبوط |
|---|---|---|---|---|
| 1 | | | | |
| … | | | | |

4. استمع لكل «مربع صوت بدون نص». هل كان فيه كلام فاته النظام؟ ________
5. هل علّم النظام كلمات خاطئة فعلاً؟ هل فاتته كلمات خاطئة لم يعلّمها؟ ________

## معايير النجاح
- 18 من 20 كلمة على الأقل تبدأ وتنتهي في المكان الصحيح (خطأ أقل من 0.1 ثانية تقريباً، أي لا تسمع جزءاً من الكلمة السابقة أو التالية).
- لا توجد كلمات مختلَقة (نص لم يُقل).
- الكلام الذي فات النظام يظهر في «مناطق صوت بلا نص».

## أرسل النتائج إلى Claude Code
أرسل: الجدول أعلاه، ومحتوى `projects\<المشروع>\02_transcript\transcript.json`
(أو قسم `summary` منه على الأقل)، وآخر سطور `logs\vpa.log`.

إن فشلت المعايير سنجرّب بدائل قبل المرحلة 2: نموذج محاذاة عربي آخر،
أو تعديل حدود الثقة، أو محرك faster-whisper للمقارنة.
