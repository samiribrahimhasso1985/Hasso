# هوية «اكتشافات» داخل الفيديو

## 1. الشعار المرافق للمونتاج (9:16)

| العنصر | القيمة |
|---|---|
| الملف | `assets/brand/logo_calligraphy_white.png` (الخط العربي فقط – كلمة IKTISHAFAT تختفي في الحجم الصغير) |
| المكان | أعلى اليمين، **تحت** شريط أزرار المنصة العلوي |
| الموضع (1080×1920) | من الأعلى 230 بكسل، من اليمين 64 بكسل |
| الحجم | عرض 250 بكسل (≈ 23% من عرض الشاشة) |
| الشفافية | 75% |
| الظل | ظل أسود خفيف حتى يبقى واضحاً فوق اللقطات الفاتحة |
| الظهور | يظهر تدريجياً بعد ثانية من بداية الفيديو |
| الاختفاء | يختفي قبل الخاتمة (لأن الخاتمة فيها الشعار الكبير) |
| في دافنشي | على مسار فيديو مستقل اسمه **Logo** فوق كل المسارات، فيمكن تحريكه أو إخفاؤه |

## 2. المناطق الآمنة في 9:16 (تيك توك / ريلز / شورتس)

| المنطقة | المحجوب | القاعدة |
|---|---|---|
| الأعلى | 0 – 200 بكسل | لا شعار ولا نص |
| الجانبان | 150 بكسل من كل جانب، بين 760 و 1520 بكسل | أزرار الإعجاب والتعليق: يميناً في التطبيق الإنجليزي ويساراً في العربي، لذلك نترك الجانبين |
| الأسفل | آخر 400 بكسل | الوصف واسم الحساب |

**الترجمة** تبقى بين 170 و 910 بكسل أفقياً، وفوق خط 1520 بكسل.
**الملصقات** تُوضع في المنطقة الوسطى ولا تغطي الشعار ولا الترجمة.
