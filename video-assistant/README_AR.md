# مساعد إنتاج الفيديو – Claude Video Production Assistant

نظام شبه آلي لتحضير الفيديو الاحترافي على Windows 11 مع Claude Code و DaVinci Resolve 21.

> **الحالة الحالية: المرحلة 1 فقط (تحليل الفيديو والتفريغ الصوتي).**
> المراحل الأخرى لم تُبنَ بعد. راجع [خطة المراحل](docs/ROADMAP_AR.md).

---

## ماذا تفعل المرحلة 1؟

1. تأخذ ملف الفيديو أو الصوت (MP4 أو MOV أو WAV).
2. **تحفظ نسخة من الأصل** داخل مجلد المشروع للقراءة فقط، وتتحقق منها ببصمة SHA-256. الملف الأصلي لا يُعدَّل أبداً.
3. تقرأ معلومات الملف: المدة، الأبعاد، عدد الإطارات، النسبة (9:16 أو 16:9).
4. تستخرج الصوت عبر FFmpeg (أحادي، 16 كيلوهرتز) للتحليل، وتنبّه إن كان الصوت منخفضاً جداً أو مشبعاً.
5. تفرّغ الكلام العربي باستخدام **WhisperX** مع توقيت لكل كلمة (محاذاة صوتية بنموذج wav2vec2 العربي).
6. **تعلّم الكلمات المشكوك فيها** للمراجعة اليدوية:
   - محاذاة ضعيفة أو ثقة منخفضة،
   - توقيت تقديري أو مفقود،
   - مدة كلمة غير طبيعية أو تداخل في التوقيت،
   - أرقام أو حروف لاتينية (لا يستطيع نموذج المحاذاة العربي توقيتها بدقة)،
   - تكرار مشبوه (خطأ معروف في Whisper).
7. **تكشف مناطق فيها صوت بدون نص** – أي أماكن قد يكون فيها كلام لم يلتقطه النظام، لتستمع إليها بنفسك.
8. تُنشئ **صفحة مراجعة** تفتح في المتصفح: انقر على أي كلمة لتسمعها وحدها.

**النظام لا يخترع كلاماً أبداً.** إن لم يسمع كلمة فلن يضيفها، بل يعلّم المكان للمراجعة.

## التثبيت (مرة واحدة)

### المتطلبات
- Windows 11
- اتصال بالإنترنت في أول تشغيل (لتحميل النماذج، حوالي 3–4 غيغابايت لنموذج large-v3)
- يُفضَّل كرت شاشة NVIDIA. بدونه يعمل النظام لكن ببطء (قد يستغرق فيديو 10 دقائق أكثر من 30 دقيقة).

### الخطوات
1. ثبّت Python 3.12 (إن لم يكن مثبتاً). افتح **Terminal** واكتب:
   ```
   winget install -e --id Python.Python.3.12
   ```
2. انقر نقراً مزدوجاً على **`setup_windows.bat`**.
   - إن لم يكن FFmpeg مثبتاً سيثبّته تلقائياً، ثم يطلب منك إغلاق النافذة وتشغيل الملف مرة أخرى.
   - سيكتشف كرت NVIDIA ويثبّت النسخة المناسبة من PyTorch.
3. في النهاية يجب أن ترى: **النظام جاهز ✓**

للتحقق لاحقاً: انقر على **`check_system.bat`**.

## الاستخدام

1. **اسحب ملف الفيديو وأفلته فوق `analyze_video.bat`**.
2. انتظر حتى ينتهي التحليل. ستظهر الخطوات واحدة تلو الأخرى.
3. ستُفتح صفحة المراجعة تلقائياً في المتصفح.

### صفحة المراجعة
- **أصفر**: كلمة تحتاج مراجعة.
- **أحمر**: كلمة مشكوك فيها بشدة (بدون توقيت، تكرار، ثقة منخفضة جداً).
- **مربع أحمر متقطع**: صوت بدون نص – استمع وتأكد.
- انقر على كلمة لسماعها. **Shift + نقر** لتشغيل المقطع من تلك الكلمة.
- مرّر الفأرة فوق الكلمة لرؤية التوقيت ودرجة الثقة.

> تصحيح النص وإعادة المحاذاة سيكونان في المرحلة 2.

### إن توقف التحليل أو أُغلقت النافذة
أعد سحب نفس الملف فوق `analyze_video.bat`. سيكمل من الخطوة التي توقف عندها ولن يعيد ما أنجزه.

## الربط مع DaVinci Resolve Studio (فحص الاتصال)

1. افتح DaVinci Resolve Studio.
2. من القائمة: **DaVinci Resolve ← Preferences ← System ← General**
   واضبط **External scripting using** على **Local**، ثم احفظ وأعد تشغيل البرنامج.
3. انقر نقراً مزدوجاً على **`check_resolve.bat`** (والبرنامج مفتوح).
4. يجب أن ترى: **✓ تم الاتصال بـ DaVinci Resolve** مع اسم النسخة.

هذا الفحص **للقراءة فقط** ولا يغيّر شيئاً في مشاريعك.
لا تحتاج لضبط متغيرات البيئة يدوياً؛ البرنامج يجد ملفات دافنشي في أماكنها الافتراضية تلقائياً.

## مجلد المشروع

كل فيديو له مجلد داخل `projects\`:

```
projects\<اسم الفيديو>\
    00_source\       نسخة الأصل (للقراءة فقط) + source_info.json
    01_audio\        الصوت المستخرج للتحليل
    02_transcript\   transcript.json + review.html (صفحة المراجعة)
    03_subtitles\    (المرحلة 3)
    04_stickers\     (المرحلة 4)
    05_resolve\      (المرحلة 5)
    06_color\        (المرحلة 6)
    07_export\       (التصدير النهائي – فقط بعد موافقتك)
    logs\vpa.log     سجل الأخطاء والتفاصيل
    state.json       حالة كل خطوة
```

## الإعدادات (بدون تعديل الكود)

لا تعدّل أي ملف برمجي. لتغيير الإعدادات اطلب من Claude Code، أو أنشئ ملف
`config\user_config.json` يحتوي فقط على ما تريد تغييره، مثلاً:

```json
{ "transcription": { "model": "medium", "device": "cpu" } }
```

| الإعداد | المعنى |
|---|---|
| `transcription.model` | `large-v3` (الأدق، الافتراضي) أو `medium` أو `small` (أسرع وأقل دقة) |
| `transcription.device` | `auto` أو `cuda` (كرت الشاشة) أو `cpu` |
| `transcription.initial_prompt` | جملة توجّه النموذج نحو اللهجة العراقية |
| `uncertainty.min_align_score` | أقل درجة محاذاة مقبولة (أعلى = تعليم كلمات أكثر) |
| `speech_coverage.silence_threshold_db` | حد الصمت لكشف مناطق الصوت بلا نص |

## حل المشاكل

| المشكلة | الحل |
|---|---|
| «محرك التفريغ الصوتي غير مثبت» | شغّل `setup_windows.bat` |
| «تعذّر تحميل نموذج التفريغ من الإنترنت» | أول تشغيل يحتاج إنترنت. تحقق من الاتصال وأعد المحاولة |
| خطأ CUDA أو cuDNN | أنشئ `config\user_config.json` بالمحتوى `{"transcription": {"device": "cpu"}}` |
| «الذاكرة غير كافية» | استخدم نموذج `medium` |
| أي خطأ آخر | افتح `projects\<المشروع>\logs\vpa.log` وأرسل آخر 30 سطراً إلى Claude Code |

## ملاحظات صادقة عن الدقة

- Whisper لا يدعم «اللهجة العراقية» كخيار مستقل؛ يتعرّف على العربية عموماً. نوجّهه نحو العراقية بجملة توجيهية، لكن الكلمات العامية ستحتاج مراجعة أكثر.
- **لم يتم اختبار المحاذاة العربية على فيديو حقيقي بعد.** يجب تنفيذ [اختبار المرحلة 1](docs/STAGE1_TEST_AR.md) على فيديو حقيقي قبل الانتقال للمرحلة 2.
