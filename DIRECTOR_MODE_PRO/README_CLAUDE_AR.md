# تسليم المشروع إلى Claude Code

## طريقة الاستخدام
1. فك ضغط `DIRECTOR_MODE_PRO_CLAUDE_STARTER.zip` على جهازك.
2. افتح مجلد `director_mode_pro` داخل Claude Code.
3. تأكد أن Claude Code يرى ملف `CLAUDE.md` في جذر المشروع.
4. أرسل إلى Claude الأمر التالي:

> اقرأ CLAUDE.md وREADME.md وdocs/TASK_FOR_CLAUDE.md، ثم افحص المشروع كاملاً ونفّذ المرحلة الأولى فعلياً. حافظ على الملفات الحالية، واجعل المشروع قابلاً للبناء، ولا تدّع دعم كاميرا لم يتم اختباره على الجهاز الحقيقي. نفّذ خطوة خطوة وشغّل الاختبارات والبناء إن كانت الأدوات متاحة.

## تنبيه
الملفات الحالية هي أساس برمجي أولي وليست APK نهائياً. عقود Camera Adapter لا تعني أن Sony أو DJI متصلتان حالياً. يلزم اختبار البروتوكولات على الأجهزة الحقيقية قبل تفعيل أي ميزة.
