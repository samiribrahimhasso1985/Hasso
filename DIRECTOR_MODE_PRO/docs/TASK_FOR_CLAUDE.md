# تنفيذ المرحلة الأولى — DIRECTOR MODE PRO

افتح المشروع الحالي واقرأ `CLAUDE.md` و`README.md` وكل ملفات Kotlin وGradle قبل التعديل.

المطلوب الآن تنفيذ Milestone 1 فعلياً:

1. افحص بنية المشروع واكتشف أخطاء البناء الموجودة قبل إجراء أي تعديل.
2. راجع عقود الكاميرات في `camera/core`، وحسّنها عند الحاجة دون كسر واجهة Compose الحالية.
3. أنشئ طبقة إدارة مصادر الكاميرات: إضافة مصدر، تعديله، حذفه، اختيار نوع الاتصال، وعرض حالة الاتصال والإمكانيات.
4. احفظ المصادر محلياً بحيث تبقى بعد إغلاق التطبيق وإعادة فتحه. اختر DataStore أو Room واذكر سبب الاختيار.
5. أضف مصدر RTSP للاستقبال فقط إذا أمكن إدخال رابط بث حقيقي من المستخدم. لا تنشئ بثاً وهمياً.
6. اترك Sony FX3 وDJI Action 5 Pro كأهداف تكامل غير مفعلة حتى يتم التحقق من بروتوكول الاتصال على الأجهزة الحقيقية.
7. أضف اختبارات للوحدات الأساسية وحالات الاتصال.
8. حافظ على التصميم السينمائي الداكن وعلى اسم الحزمة `com.directormodepro.app`.
9. شغّل Gradle build والاختبارات إذا كانت البيئة تحتوي على Android SDK. إذا لم تتوفر، اذكر ذلك ولا تدّع نجاح البناء.
10. حدّث README بتعليمات بناء APK والقيود المعروفة.

ابدأ بالتنفيذ مباشرة، ولا تكتفِ بتقديم خطة أو أمثلة نظرية. لا تحذف أو تستبدل ملفات المشروع دون فهمها أولاً.
