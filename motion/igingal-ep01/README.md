# IGINGAL — الحلقة الأولى · موشن بأسلوب الورق المقصوص

فيديو موشن جرافيك (1920×1080، 30 إطارًا/ث، 1:59) مبني على نص «الحلقة الأولى — السؤال».
كل العناصر مرسومة برمجيًا كطبقات ورق ممزّق الحواف مع ظلال وملمس ورق؛ لا توجد صور خارجية.

## الملفات
- `index.html` — المشاهد والحركة (تُحدَّد بالزمن فقط، فيصبح التصيير قابلًا للتكرار إطارًا بإطار).
- `render.js` — يصيّر الصفحة إطارًا إطارًا عبر Playwright ويمرّرها إلى ffmpeg.
- `audio.sh` — موسيقى خلفية مولّدة (درون منخفض + ريح + صوت ورق عند كل انتقال تمزيق). لا يوجد صوت راوٍ.
- `fonts/` — Amiri، Reem Kufi، Noto Sans Cuneiform (رخصة SIL OFL).
- `igingal-ep01.mp4` — النسخة النهائية.

## التصيير
```bash
NODE_PATH=$(npm root -g) node render.js silent.mp4 30
./audio.sh score.wav
ffmpeg -i silent.mp4 -i score.wav -c:v copy -c:a aac -b:a 192k -shortest igingal-ep01.mp4
# معاينة لقطات ثابتة:
NODE_PATH=$(npm root -g) node render.js --stills 5,30,60 stills/
```

## ملاحظات الأمانة
- عبارة «قراءة فلسفية معاصرة — ليست رأيًا ورد في نص سومري» تظهر على الشاشة في مشهد التحليل.
- «IGINGAL صياغة أنشأناها نحن… ولا نزعم أنها عبارة سومرية معروفة» تظهر نصًا في مشهد الحقيقة.
- شعار السلسلة يستخدم 𒅆𒅅 (IGI + IG) كما في الهوية، بينما يعرض مشهد المفردات الرمز الصحيح لـ gal (𒃲).
